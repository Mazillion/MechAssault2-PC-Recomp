## How the project avoids distributing the game

A recompilation turns a game's program into source code. That code is still the game's program in another form, so it is never shared. Everything that comes from the game is produced on your PC, from your disc, while you install:

- The game's program and data are read from your disc.
- The translated C code is generated by [xboxrecomp](https://github.com/sp00nznet/xboxrecomp) during the install. It is never in this repository.
- The project's changes to that code are stored as line numbers plus lines written for this project, never as lines of translated code. [docs/patches.md](docs/patches.md) explains how.
- The PC menus and button prompt icons are built from your disc's own files. Only file names, layout numbers and hashes are stored here.
- Shaders are compiled by your graphics driver as you play, and the optional upscaled textures and videos are made on your PC. No pre-made packs are distributed.

What is distributed is the project's own source code, the xboxrecomp toolkit, third-party open-source components under their own licences, and the installer built from them.
