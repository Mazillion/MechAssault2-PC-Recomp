MechAssault 2 PC recompilation - changes
========================================

You have version {{VERSION}} (build {{BUILD}}).


1.1.6
-----
- Report a problem: in the game's pause menu and Audio settings, in the
  Start menu, in the installer, and in the window that opens when the game
  crashes or stops responding. It makes one zip with the logs, settings
  and PC details (no user name, PC name or personal files) and has a box
  to say what happened. Send report sends it to the developer and shows
  a report number; nothing is sent until you press it, and sent reports
  are kept for 60 days. Every report is also saved in
  %LOCALAPPDATA%\MechAssault2\Diagnostics, and Save a copy instead saves
  it there without sending (no internet needed).
- The game's log now notes once a minute how smoothly the game and its
  sound are running, which helps with reports of crackling or slowdowns.
- On PCs with few CPU threads, the game gives its sound more priority as
  soon as the sound starts to fall behind. In our tests that made
  crackling much rarer on those PCs; other PCs are unchanged.
- The installer notes in its log every minute that it is still working
  while a big file compiles, says when it is taking longer than estimated,
  and explains that high CPU use and fan noise during the build are normal.
- On PCs with less than 24 GB of memory, the installer builds the largest
  game files with less memory from the start (the game code is the same).
- After a power cut or a crash during an install, the next run says so and
  carries on from the finished steps.
- "Keep my PC responsive" is preselected on laptops running on battery and
  on PCs with 4 CPU threads or fewer.
- Diagnostics and reports also leave out the PC's name and e-mail
  addresses, and names inside crash dumps are overwritten.
- The scenario editor is the same as in 1.1.5.

1.1.5
-----
- The installer is more reliable on PCs with less memory: if the build runs
  low on memory, it uses less memory, or waits until some is free, and
  carries on by itself without losing progress.
- The game and the scenario editor are the same as in 1.1.4.

1.1.4
-----
- A new, simpler installer window: choose your disc image, press Install.
- The installer fixes more problems on its own, such as low memory, a busy
  file or an interrupted download.
- When a download fails, the installer says why (no internet, a Wi-Fi
  login page, a proxy).
- After a restart needed by the Microsoft C++ tools, the installer carries
  on by itself.
- On a brand-new Windows PC, the FFmpeg download no longer stops with a
  "check your internet" message.
- In the menus, the difficulty list and its arrows work with the mouse,
  and on the name entry screen Back and Enter can be clicked. With a
  keyboard or mouse, Enter there is labelled "Done".
- The scenario editor is the same as in 1.1.3.

1.1.3
-----
- With HD textures, some textures no longer show grey for a moment before
  the HD version pops in the first time a level loads.
- The installer works on more PCs and handles more problems on its own.
- The optional enhanced cutscenes now also work on AMD and Intel graphics
  cards. This is new and hasn't been tested on those cards yet.

1.1.2
-----
Installer
- A failed or cancelled optional step (enhanced textures or videos) no
  longer undoes the game install. The game stays installed at the new
  version and ready to play, and Resume tries only the enhanced content
  again. Before, a failed update went back to the previous version.
- A clearer message when the texture tool is stopped by something outside
  the installer (its window closed, or security software ended it), with
  a hint that antivirus may be blocking Python. The tools it runs no
  longer have a console of their own.
- Installing to a folder with commas or brackets in its name (like a disc
  dump folder) no longer stops the build at the final link: the build
  then runs in a plain folder such as C:\MA2RecompBuild-xxxx, as it
  already did for accented letters.
- When compiling fails with a compiler or linker error, the message now
  names that error (and suggests a simple install folder such as
  C:\Games\MechAssault 2) instead of pointing at antivirus first.
- HD textures now also work on AMD and Intel graphics cards, through
  Vulkan (Real-ESRGAN's realesrgan-ncnn-vulkan, downloaded and checked
  during the install). This is new and not yet tested on those cards.
  NVIDIA cards keep the PyTorch upscaler; the enhanced cutscenes still
  need an NVIDIA card.
- More reliable startup and clearer reports when something blocks the
  install.

1.1.1
-----
Installer
- Collect diagnostics is now always on the installer's first page, even
  with nothing installed. It is also on the error screen of a failed
  install (the zip names the step that failed and holds the install log)
  and on the banner for an interrupted install.
- The log on the install page no longer hides the note above it ("Lines
  marked normal are expected ..."), and the failure screen's buttons wrap
  onto a second row instead of running past the window edge.
- The --diagnostics switch no longer needs --dest.

1.1.0
-----
Game
- 2v2 Capture the Flag: bots no longer stall at the stands. Four bot
  behaviours that fix this are on by default (ExtractHome, CapAnyway,
  LoneGround, StageComing); each has a switch under [Bots] in
  pc_settings.ini.
- Custom missions: messages that fire together are queued and all show.
  Retail levels run the original code.
- Custom missions: Mission failed (Retry / Quit) and Mission complete
  (Continue / Replay) screens, with the Won / Lost text from the editor.
  The world stands still while they show.
- Custom cutscenes: a new [Cutscenes] NoSkip setting keeps the listed
  cutscenes from being skipped.
- Custom missions: the mission's own archive is mounted again after a
  Retry.
- Custom levels: a resized lake or river, and a cut wall, base or
  parking lot, are drawn at the size you saved. The ground around a
  resized lake no longer goes dark.
- Custom levels: the sky you pick now shows on multiplayer maps (Starry
  space was black), and the Dust storm weather works on them.
- The scenario editor opens from Custom Scenarios and takes you back to
  it without restarting the game. Test goes straight into the mission.
  While the editor is open the game waits quietly in the background and
  uses very little of your PC.
Scenario Editor
- A large update: a new Build tab, one snapping system, size handles, a
  cutscene timeline, a full Environment tab and a new user guide (Help >
  User guide).
  Where things sit:
  - The ground you see is the ground that is saved: sculpting works on
    the game's stored height steps, so nothing shifts when you reopen a
    map.
  - Roads, bases, plates and paved squares are layered sheets: each sits
    a few centimetres above the one below, so the game and the editor
    draw the same thing and the flicker is gone. Roads sit above bases
    by default; Bring forward and Send back override it.
  - Objects stand on the top surface under them (a sheet, else the
    ground), never on a tree or roof unless asked. The readout shows
    what an object stands on.
  - Ground tools carry what stands on them. Fit ground to road protects
    its neighbours and says what it changed.
  - Slopes: choose Level the ground, Tilt or Float before the click; the
    ghost shows the gap. Plates default to Level, roads to Tilt.
  - Water basins protect neighbours and follow the water. Check scenario
    reports floating, buried, overlapping, deep and hanging pieces and
    has Show buttons.
  - A pad moves as a whole, and buried pads are flagged. A road joined
    to a neighbour in Float keeps the joint height.
  Snapping:
  - One snapping solver for every modular family: a joint pulls the
    piece only when the cursor is near it, Q and E step through ways to
    join, Shift places freely.
  - Cross-family snaps: buildings on a base, a road beside or ending at
    a base edge, a wall at a corner, flush-corner base runs. Aiming at
    an open end joins it, for walls and roads.
  - Grid (off by default, 1-20 m, drawn), 15 degree angle steps, a snap
    bar, Ctrl+G and a typed Facing.
  - Moving a piece snaps like placing it: body drag, arrows, nudges and
    the paste ghost all join.
  Controls:
  - One table of actions: every key is in it, and hints, tooltips and
    Help are generated from it. Help and the user guide use the key
    names from your own bindings.
  - Undo keeps 200 steps. Repeated Q/E, nudges and slider drags merge
    into one step, and the unsaved mark clears when you undo back to the
    saved state.
  - Box select from a drag on empty ground, a right-click menu on
    objects, double-click selects the same type, paste shows a ghost.
  - PgUp / PgDn and arrows nudge, a lift knob that cannot hide, number
    readouts, a floor so nothing goes underground silently, group turn.
  - Ctrl+wheel changes brush size, Shift+wheel strength, [ ] one even
    step; a ring shows size and half strength. Alt+drag turns the view.
  - One name per command and one text per hint. The layout is checked at
    1280 x 720, 1584 x 861, 1920 x 1080 and 3840 x 1600; at 3840 x 1600
    the interface starts at a larger scale.
  Panels and palette:
  - One Build tab with an always-visible tool strip (Select, Place,
    Scatter, Roads and walls, Sculpt, Paint, Water, Starts).
  - One palette browser for Place and Scatter: filter chips, every
    object listed, brush-set chips, drag and drop, ranked search by
    visible name, plain names with no raw codes, sizes on modular
    pieces.
  - Help is a topic list with a page and Find in Help; Getting Started
    and the user guide come from the same text.
  - Graphics memory figure per template and live in the footer. The New
    dialog names themes by what they contain.
  - Add a plant from another level (Paint > Plants), or scatter it as
    objects.
  - The first-run window opens big at a larger interface scale, and the
    Helpers panel is pinned to the right.
  Sizing:
  - What can be cut is decided in one place. Collision follows the cut,
    cut destructibles default to Cannot be destroyed, and a cut end
    joins the next piece.
  - Orange size handles on the map for roads, bases, walls, fences,
    gates and bridges, with a ghost of the cut part, and a Size panel
    around a top-down outline that says why something cannot be cut.
  - Water is placed by dragging, with eight edge and corner handles and
    a Level knob; the basin follows. Default size 60 x 40 m.
  - Cut wall, bridge and road ends snap to base edges and building faces
    and say what they meet.
  - Cut .road, .node and .mesh files are now written with CR LF. Version
    1.0.9 wrote bare LF, which the game's reader does not split, and a
    map with a cut road could crash the game when loading. Check warns
    about old cut maps until you save them again.
  Terrain, paint and scatter:
  - The ground colour map is kept lossless in the project and saved to
    the game uncompressed, so a painted tint reaches the game exactly.
    Save As never renames a name you typed.
  - Sculpt: Raise, Lower and Roughen are one pass per stroke with a
    Height per stroke setting; the smallest brush follows the map's
    height grid; height-point dots, a cursor readout, Shift+click
    straight lines, Flatten pick.
  - Ramp tool: two clicks, one undo step.
  - Painting is one pass per stroke with a strength per tool. Ctrl
    reverses Texture, Boundaries and Plants.
  - Scatter brush: count by area, spacing by model size, keeps off
    roads, bases and buildings, optional lean and
    follow-the-slope, Ctrl erases, Shift draws a line.
  Missions:
  - Briefing: a timed start-of-mission message (pages of up to six
    lines), also used as the description in Custom Scenarios.
  - Message speaker, an Add a sound button, and Won / Lost texts for the
    end screens.
  - Player-outside-a-circle triggers now write the values the game reads
    (old files open as 2).
  - Base War maps write the objective settings the game needs, so they
    no longer end after 5 seconds. "Win: every objective done" stays off
    while there is no objective to wait for, with a Check warning, so a
    mission is not won at once.
  - Objectives can be completed by a place, a delay, destroyed units or
    a trigger. Units can arrive after a delay, and orders given to a
    reinforcement start when it arrives. Lose if time runs out. An
    orders chooser (walk once, patrol, defend, follow, attack); Neutral
    units warn that they ignore orders.
  - Defend a point walks the unit to the spot first, then guards it.
  - A side change gives an empty unit a pilot ("It has a pilot from the
    start"), so it fights.
  - Put the player in a vehicle ships the new vehicle's files and works
    from on foot and from a 'Mech.
  - The damage trigger reads "Fires at health left (%)"; counters list
    the triggers they count.
  - The trigger list is split into Your triggers and From the level,
    with Pick on map and one action editor everywhere.
  Cutscenes:
  - Add a shot from the current view, intro cutscenes start at 0 s, and
    Check flags long holds, missing paths and a mission that ends
    mid-cutscene.
  - Timeline strip with shots and total length, typed lengths, reorder
    by dragging, preview in the game's wide band.
  - Frame it / Use this view, shot glyphs on the map, pickable eye
    points.
  - Shots play at their authored position (a path used to start at a
    marker high above the map).
  - Events on the timeline (sounds, messages, unit orders), When it ends
    actions, and a Check fix that moves old shots off the flyby marker.
  - Listen to your own clips from the editor; cue pickers show the words
    of retail cues.
  - Hold the fight (enemies by default), a player-can-skip checkbox, and
    held units wake again after the cutscene, including on a replay. A
    multi-shot cutscene that can replay uses hard cuts on both plays.
  Look and weather:
  - Environment tab: one Look section, Lightning always shown, fog
    Default / Light / Medium / Thick, Sun or Moon with direction 0-359
    and height, a status line for every control.
  - Light cones the game does not draw are culled, the lightning preview
    lights models and the sky as the game does, snow follows the camera
    heading, and there is no black band at the horizon.
  - Skies match the game: Bright overcast, Dark blue storm clouds and
    Starry space now look the same in both, and the picked sky is
    shipped with the map. Dust storm is a scenario effect that works on
    multiplayer maps. On a multiplayer map the Sky list marks Planet,
    which is black in the game.
- Help > About and the file properties show 1.1.0.

1.0.9
-----
First public release.

Game
- Logs no longer contain your Windows user name: folders in your user
  profile are written as %LOCALAPPDATA%, %APPDATA% or %USERPROFILE%,
  so a log is safe to post in a bug report.
- If the game crashes or stops responding, the message box now points
  you to Collect diagnostics first. Share the crash dump file only if a
  maintainer asks for it.
Installer
- FFmpeg (cutscene playback) is no longer inside the installer: it is
  downloaded during the install from where it is published, and every
  file is checked before use.
Scenario Editor
- Its crash log and messages no longer contain your Windows user name.
- Help > About and the file properties show 1.0.9.

1.0.8
-----
Game
- Story cutscenes now fill the screen at full resolution on widescreen
  and ultrawide displays, instead of a small 4:3 picture with side bars,
  and run at 60 FPS instead of 30.
- The three "incoming transmission" cutscenes keep their original 4:3
  frame.
- Two new settings in pc_settings.ini, [Display] section:
  CinematicView (2 = fill the screen, the default; 1 = fill up to 16:9;
  0 = original 4:3 with side bars; 3 = wide) and CinematicFrameCap
  (cutscene frame rate, default 60; 0 = use the normal frame limit).
  Filling the screen needs Aspect ratio set to Automatic.
Scenario Editor
- Help > About and the file properties show 1.0.8.

1.0.7
-----
Game
- Bot VTOLs pick up their Battle Armor teammates faster: they glide down
  on the way in instead of stopping high and sinking, and take off as soon
  as a rider latches on.
- A VTOL carrying a Battle Armor no longer flies so low that its rider is
  knocked off by buildings or the ground, and steers round tall towers.
- With a rider aboard, a VTOL heads straight for the objective instead of
  breaking off to fight, and its rider stays on until it gets there.
- VTOLs no longer get stuck at the edge of the map on the way out of base.
- A VTOL no longer keeps chasing a Battle Armor that has stopped trying
  to board (for example one that has turned to fight).
Scenario Editor
- Help > About and the file properties show 1.0.7.

1.0.6
-----
Game
- Bots walk over small rises instead of jet-hopping them and no longer
  cut over mounds, so they reach objectives more directly.
Scenario Editor
- Help > About and the file properties show 1.0.6.

1.0.5
-----
Game
- Bots: smoother landings after a jump and steadier first steps.
- Bots no longer queue up at the wide exits of their base.
- Snatch It!: bots no longer give up on the data core from far away.
- Tanks no longer wrongly avoid slopes, and bots no longer bail out of
  tanks that are still working.
- Ill Wind: the two teams now reach the objectives at a closer pace.
Scenario Editor
- Help > About and the file properties show 1.0.5.

1.0.4
-----
Game
- Bots: more even objective races between the two teams.
  - Snatch It!: bots no longer dither between two data cores.
  - No Man's Land: units no longer stop for VTOLs that are far away.
  - Two bots meeting at a narrow pass no longer wait for each other.
  - Bots no longer turn the wrong way after landing.
  - Fewer stalls before a leap or a jump-jet climb; giving way to a
    teammate no longer cancels a jump.
  - A bot walking a chain of waypoints holds its course.
Scenario Editor
- Help > About and the file properties show 1.0.4.

1.0.3
-----
Game
- Lightning storms no longer make the whole scene pulse lighter and darker:
  the flash now lights the units (Mechs, vehicles, pilots), not the ground
  and sky.
- Bots: both teams reach contested objectives at a fairer pace in Snatch It!
  and Check It! (better climbing over ledges and up basin walls, buildings
  taller than 40 m are seen as walls on Rush Hour, less stutter after
  boarding a vehicle).

1.0.2 - first release outside the development team
--------------------------------------------------
Game
- First launch opens borderless fullscreen at your desktop resolution and
  never picks an enhanced texture pack that is not installed.
- The Multiplayer entry for offline play is now called BOT MATCH. A new
  profile starts with bots (3 Red, 4 Blue, 5 in free-for-all, skill Mixed);
  the bot rows explain the team sizes.
- Key-binding rows are named by what they do; "Press any key or mouse
  button..." when choosing a key. Menu key hints read [Esc] Back and similar.
- The game pauses and goes silent when another window has focus (both can be
  turned off in the settings file).
- Esc on a message at the main menu closes the message instead of asking to
  quit.
- Quitting restores the Windows Sticky Keys shortcut.
- Freezes are detected: after 30 seconds the game writes a hang report and
  dump, and after 2 minutes it offers to close. The crash message names the
  files to send. The log starts with the version and the graphics card.
- The shader cache moved to %LOCALAPPDATA%\MechAssault2\ShaderCache.
- Bot match recordings are limited to the newest 4, at most 150 MB each.
- Custom Scenarios: two scenarios with the same name are told apart by file
  name; unfinished scenarios are not listed; skipped files get a short note
  with the reason; scenarios from older editors get a "save it again" hint.
- Bots: an overheated 'Mech waits before jumping, a boxed-in 'Mech finds a
  firing spot sooner, harder bot fire (BurstFire), fixes for BattleArmor
  walking, VTOL climbing at high frame rates and many map-specific routes.
- Fixes for rare freezes and crashes in the sound code, and for missing voice
  lines.

Scenario editor
- Help > About shows the version; Help > User guide opens the guide.
- Scenario files record the editor version; File > Update old scenarios...
  updates files saved with older editors (the old file is kept as .bak).
- New scenarios get unique names ("New Mission 2"); a name used by another
  scenario is reported on save.
- A file copied in Explorer gets its own identity when opened.
- Damaged files are detected when opened.
- Name and description length limits (60 and 250 characters).
- The New scenario dialog fits on small and high-DPI screens.

Installer
- Checks every file of the disc dump and names damaged files.
- Accepts a folder copied from the disc as well as an .iso/.xiso.
- Free space on C: no longer blocks an install to another drive.
- Uninstall and Collect diagnostics on the first page.
- Clearer messages when it cannot start, when a download fails and on the
  failure screen, with buttons to go back to the right page.
- Ships Controls.txt and the Docs folder; licences of every component.
