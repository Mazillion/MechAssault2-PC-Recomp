MechAssault 2 PC recompilation - install guide (version {{VERSION}})
====================================================================

The installer builds a PC version of MechAssault 2 from your own disc. It
contains no game data: the game's program, art, sound and levels come from
your disc image. It runs on your PC and takes about 15 minutes on a fast
8-core PC; on 4 cores or with 8 GB of memory it can take an hour or more.


WHAT YOU NEED
-------------
- Your own MechAssault 2 disc, US (NTSC) retail version, dumped to an .iso or
  .xiso file, or a folder copied from the disc. Other regions are not
  supported. The installer checks every file of the dump.
- 64-bit Windows 10 version 1903 or later, or Windows 11.
- A graphics card with DirectX 11 (feature level 11.0).
- 8 GB of RAM recommended.
- About 5 GB free on the drive you install to (about 3 GB stay used).
- Microsoft's C++ Build Tools. If they are missing the installer can install
  them for you: about 8 GB more on C:, 10-30 minutes, and administrator
  approval.
- An internet connection. The installer downloads FFmpeg, which plays the
  cutscenes (from gyan.dev, where it is published; every file is checked
  before use), and if needed the Build Tools and the enhanced-content AI
  software (FFmpeg is a download of about 90 MB). Without internet on
  this PC: on another PC, download exactly this file (a newer FFmpeg
  version does not work):
  https://github.com/GyanD/codexffmpeg/releases/download/9.0.2/ffmpeg-9.0.2-full_build-shared.zip
  and put it in the install folder.

Making a good dump: clean the disc first and use a dumping tool that reports
read errors. If the installer says files from your disc are damaged, dump the
disc again.


WINDOWS WARNINGS
----------------
The installer is not code-signed, so Windows SmartScreen may say "Windows
protected your PC". If you got the installer from where you expected (compare
its SHA-256 with the one published beside the download), choose More info,
then Run anyway. Smart App Control, if it is on, can block unsigned programs
with no way around; the installer never changes it. The installer needs no
administrator rights except for Microsoft's Build Tools (their own installer
asks).


THE INSTALLER WINDOW
--------------------
1. Install MechAssault 2 - drop your disc image on the box or browse for it
   (an .iso or .xiso file, or ma2.xbe in a folder copied from the disc).
   The installer checks it. Install to shows the install folder, by default
   C:\Games\MechAssault 2 Expanded, and the free space on that drive; Change
   picks another. An earlier install keeps its own folder. The folder must
   be empty or a previous install, and not a protected, temporary or
   network folder; FAT32 drives are refused (use an NTFS drive). Install
   options has the textures (Original, HD, Ultra HD),
   the upscaled movies (see below) and the shortcuts. Its
   Troubleshooting... page holds settings for when support asks, such as
   "Keep my PC responsive" (builds more slowly in the background; chosen
   for you on a laptop running on battery and on PCs with 4 CPU threads or
   fewer). Press Install.
2. Microsoft's C++ tools - if they are missing, the installer offers to
   install them (this downloads Microsoft's own signed installer; Windows
   asks for permission, and by continuing you accept Microsoft's licence
   terms for the Build Tools, linked on that screen).
3. Installing - a progress bar and the time left. Show details lists the
   steps (reading your disc, setting things up, building the game,
   installing) and has Open log. Building the game keeps the processor
   busy: high CPU use and fan noise for 10-60 minutes are normal. If it
   takes longer than estimated the window says so and keeps working; on a
   PC with little memory it can wait for free memory and then carry on by
   itself.
4. Ready to play - Launch, Open install folder and Report a problem.

If something stops the install, the window says why and offers Try again
(finished steps are kept) and Send report (Save report when sending is not
available). Help, at the bottom left, has Help & FAQ, Collect diagnostics,
Report a problem and Open log.

Cancel, resume: you can cancel at any time. Running the installer again
with the same folder offers Continue, which keeps the finished steps.


UPDATE AND REPAIR
-----------------
Run a newer installer and choose your install folder: Update rebuilds the game
without the disc and keeps your settings and saves. Repair rebuilds the same
version and replaces game files that were changed or are missing.

After an install, the build is kept in the _work folder inside the install
folder (a few GB; it is not kept when less than 10 GB would stay free on that
drive). A later update or repair then compiles only the parts that changed,
which usually takes a few minutes. To make everything again, turn on "Rebuild
the game from scratch" in Install options.

The files an update replaces are kept in the _previous folder until the new
version has run for a minute or was closed normally; the next installer run
then deletes them. Until then, --rollback (see COMMAND LINE) goes back to the
earlier version.

The installer keeps a copy of itself in the install folder (MechAssault 2
Expanded Installer.exe), and the Start menu gets "Update MechAssault 2" when
you chose Start menu shortcuts. Run either one: when a newer version is out, it
offers "Update to" that version. Only when you press it does it download the
new installer from the project's GitHub releases page, check it against the
published one and let it update your install. If anything goes wrong, nothing
is changed and the releases page is one click away.


ENHANCED CONTENT (OPTIONAL)
---------------------------
2x or 4x enhanced textures and 2x enhanced cutscene videos are made on your PC
by AI upscaling. This needs an NVIDIA graphics card with 8 GB or more, an
internet connection (several GB of AI software are downloaded) and hours of
processing. The textures and the videos also work on AMD, Intel and other
graphics cards, through Vulkan (new; not yet tested on AMD or Intel cards;
the videos are made frame by frame there, so very slowly). 2x textures add 0.6 GB, 4x add 2.2 GB, videos add 3.5 GB (25 GB
free while they are made). You can add them later by running the installer
again.


UNINSTALL
---------
Run the installer; its first page offers Uninstall for the install it finds.
It removes the game folder and shortcuts. Tick "Also delete my settings and
saves" to remove %LOCALAPPDATA%\MechAssault2 too. Your scenarios in
Documents\MechAssault 2\Scenarios are never deleted. Microsoft's Build Tools
stay installed; remove them in Windows Settings > Apps if you like.


COMMAND LINE
------------
The installer's engine can also run without the window, for example:
  --uninstall [--yes] [--delete-user-data]
  --rollback          back to the version the last update replaced
  --update --clean-build   update or repair, everything made again
  --no-keep-build     do not keep the build for the next update
  --self-update       with --dest: update to the newest version (downloads its
                      installer from the releases page and checks it first)
  --no-self-update    no installer copy, no Update entry, no update check
  --diagnostics [--include-dump] [--include-botrec]   (the zip goes on your
                                                     Desktop)


PROBLEMS
--------
See Docs\Troubleshooting.txt. Installer logs are in
%LOCALAPPDATA%\MechAssault2\Logs (install-*.log, installer-ui-*.log,
buildtools-*.log). Report problems at {{MA2_SUPPORT_URL}}.
