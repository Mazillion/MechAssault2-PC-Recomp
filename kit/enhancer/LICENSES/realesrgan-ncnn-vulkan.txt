realesrgan-ncnn-vulkan
======================

Used to make the enhanced textures on graphics cards without CUDA (through
Vulkan). The installer downloads Real-ESRGAN's own Windows build
(realesrgan-ncnn-vulkan-20220424-windows.zip, Real-ESRGAN release v0.2.5.0)
from https://github.com/xinntao/Real-ESRGAN/releases and uses
realesrgan-ncnn-vulkan.exe, vcomp140.dll (the Microsoft OpenMP runtime, under
Microsoft's redistributable terms) and the realesrgan-x4plus model.

- realesrgan-ncnn-vulkan: MIT licence (below).
  Source: https://github.com/xinntao/Real-ESRGAN-ncnn-vulkan
- ncnn, the neural network library it is built on: BSD 3-clause licence

  BSD 3-clause licence, in Real-ESRGAN.txt in this folder.
