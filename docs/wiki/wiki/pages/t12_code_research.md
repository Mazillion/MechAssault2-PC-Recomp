# Code research

Facts about the recompiled game code gathered by reading generated C, vtables, property tables and run logs: object properties (MA* classes), scenario triggers and actions, XACT audio, radar, spawners, water, camera, save and menu code, and how editor settings map to what the game does.

Newer facts and the `status` field win; `superseded` and `historical` facts stay for the history. Facts that disagree are reconciled in `wiki/overrides.json`. Related topics: scenario and editor t04, t11, t15, t16; gameplay t05; audio t02; bots t01a, t01b, t19 to t24.
