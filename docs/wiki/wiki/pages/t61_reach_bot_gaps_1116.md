# Bot behaviour gaps: planner limits vs what each unit can really do (2026-11-16)

## Overview
Status: final (2026-11-17; M5 claw and a few runs not done, marked). Proposal for the bots owner; the bot code (read-only for the reach track) is unchanged. Planner rules with file:line are in `reach\` (NAV = ma2_bot_nav.c, PATH = ma2_bot_path.c, CTRL = ma2_bot_ctrl.c, BRAIN = ma2_bot_brain.c, FM = tools/floor_model.py). Real ability: the per-unit facts of `t60_reach_units_1116` and the in-game measurements M1-M6.

The "Can it get here?" overlay shows **Player** (real ability) and **Bots** (the stricter of planner and real ability); where they differ on a map, a gap below is the reason.
